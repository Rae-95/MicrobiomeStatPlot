# 博奥生物点样仪技术参数

## 设备概述

博奥生物点样仪支持接触式点样针和非接触式喷样喷头两种模式，适用于微阵列芯片的高通量点样制备。

## 技术参数

| 参数 | 接触式点样针 | 非接触式喷样喷头 |
|------|------------|----------------|
| 样品板规格 | 1块96 / 384孔板 | 1块96 / 384孔板 |
| 玻片容量 | 136片 | 136片 |
| 重复定位精度 | ＜5μm | ＜5μm |
| 单轮循环时间 | ＜140s | ＜160s |
| 外形尺寸 | 980mm×1250mm×1500mm | 980mm×1250mm×1500mm |
| 点样针/喷头数 | 1（2、4、8、16、32、48 可选） | 1（2、4可选） |
| 取样量 | 0.25～1.25μl | 3～50μl |
| 点样体积 | 10⁻¹～10⁰ nl量级 | 10¹～10⁴ nl量级，可调 |
| 最小样品体积 | 5μl（384孔板） | 15μl（384孔板） |
| 点间距 | ≥150μm | ≥800μm |

## 主要特点对比

- **接触式点样针**：点样体积更小（纳升量级），点间距更密（≥150μm），适合高密度微阵列芯片制备；支持多达48针并行点样，效率高。
- **非接触式喷样喷头**：无需接触样品板，减少交叉污染风险；取样量范围更大（3～50μl），点样体积可调范围宽（10¹～10⁴ nl）。

## 适用场景

该设备主要用于基因芯片、蛋白质芯片等微阵列芯片的点样制备，可应用于微生物组研究中的芯片杂交实验。
